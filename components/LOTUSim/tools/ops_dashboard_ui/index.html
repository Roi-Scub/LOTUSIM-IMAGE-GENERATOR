      OPTION SÉPARÉE · SCÉNARIO CONTINU

      Transformer un bloc en trafic coopératif

      Le bloc choisi définit les objets et conditions d’un épisode continu, sans fusion avec les autres blocs. Les caps sont calculés par le profil coopératif. Le nombre d’images demandé reste une métadonnée, pas une garantie de visibilité. La chaîne d’images indépendantes ci-dessous reste inchangée ; cette action crée seulement un nouveau plan en bibliothèque, avec contrôles limités.

      PLAN D’EXPÉRIENCE

      Blocs d’images

      Chaque bloc associe sa météo aux objets qui doivent composer ses images.

      Les objets sont placés relativement à l’observateur. Le cap décrit leur déplacement ; le relèvement décrit où ils se trouvent dans la scène. Une même classe peut apparaître dans plusieurs lignes à des distances différentes. Limites par bloc : 40 objets au total, 12 par catégorie.

      PRISE DE VUE

      Caméra observateur

      FOV vertical, caméra fixée au poste de navigation. La taille en pixels affichée est une projection géométrique approximative, sans garantie de visibilité ni de reconnaissabilité.

      Modalités de rendu

      Cet éditeur prépare des campagnes RGB. Les rendus thermique et vision nocturne restent disponibles dans les autres pipelines existants, pas dans cette campagne manuelle.
